# Rule-Based AI Chatbot

This is a simple Rule-Based AI Chatbot built using Python as part of the Artificial Intelligence Industrial Training at DecodeLabs.

## Features

* Handles greetings
* Uses if-else decision-making logic
* Runs continuously until exit command
* Responds to predefined user inputs

## Technologies Used

* Python
* Streamlit (Optional)

## Run the Project

```bash
pip install streamlit
streamlit run app.py
```

## Learning Outcomes

* Control Flow
* Conditional Statements
* Basic AI Concepts
* User Interaction Handling
